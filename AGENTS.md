# Repository guidance

## CodeGraph

Use [CodeGraph](docs/codegraph.md) for source, call-path and impact discovery.
Refresh the review checkout and pass captured context to reviewers without MCP.
Treat graph results as structural evidence; inspect unindexed or stale files directly.

## Home network

Home network: For remote debugging, file searches, command execution, transfers or iRacing data collection, use the [home-network skill](.agents/skills/home-network/SKILL.md) and [access guide](docs/home-network.md).
